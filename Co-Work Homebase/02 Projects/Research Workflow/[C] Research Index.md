# Research Index

*Your bird's-eye view of everything you're looking at or acting on.*

---

## How the folders work

| Folder | Use it for |
|---|---|
| **Watchlist/** | Something you're evaluating — research in progress, not committed yet |
| **Active/** | Something you've decided to proceed with — position open or product live |
| **Archive/** | Closed out, passed on, or done — keep for reference |

Each asset gets its own file named after it (e.g. `NVDA.md`, `BTC.md`, `Bamboo Cutting Boards.md`).
Use the **Research Kickoff Template** to create it, save it in the right folder, and move it when the status changes.

## Full workflow

```
1. Got something to look at?
   → Duplicate the Research Kickoff Template
   → Name it after the asset (e.g. NVDA.md)
   → Save it in Watchlist/Stocks/ (or Crypto/ or FBA/)

2. Finished your analysis?
   → Fill in the Verdict section
   → If PASS → move file to Archive/
   → If BUY / GO → move file to Active/ and run the Post-Decision Checklist

3. Position closed or product wound down?
   → Move file from Active/ to Archive/
```
