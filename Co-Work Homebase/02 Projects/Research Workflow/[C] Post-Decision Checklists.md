# Post-Decision Checklists

*You've made your call. Now work through the right list.*

---

## Stocks

**Use after verdict: Buy**

- [ ] Define entry point — what price am I buying at? (market or limit?)
- [ ] Position size — how much am I allocating? What % of portfolio?
- [ ] Set stop loss — what price means I was wrong?
- [ ] Set price target — where am I taking profit?
- [ ] Place the order
- [ ] Set alerts — at stop loss and target price
- [ ] Log the trade — entry price, thesis in one sentence, and what would change my mind
- [ ] Set a review date — when am I checking back in on this?

---

## Crypto

**Use after verdict: Buy**

- [ ] Check exchange/wallet — do I have the right setup for this asset?
- [ ] Define entry strategy — lump sum or DCA? If DCA, over what timeframe?
- [ ] Position size — how much am I allocating?
- [ ] Execute the purchase
- [ ] Move to wallet if holding long-term (don't leave on exchange)
- [ ] Set price alerts — target price and stop/exit level
- [ ] Log the trade — entry price, thesis in one sentence, timeframe
- [ ] Set a review date — when am I reassessing?

---

## FBA Product

**Use after verdict: Go**

- [ ] Final margin check — COGS + FBA fees + shipping vs. selling price. Is the margin still there?
- [ ] Shortlist suppliers — find 3–5 on Alibaba or equivalent
- [ ] Request samples — contact suppliers, get samples ordered before committing to inventory
- [ ] Competitor check — look at top 3 listings: pricing, review count, review quality, weaknesses
- [ ] Calculate break-even — minimum order quantity, total capital needed, weeks to break even
- [ ] Draft the listing — title, bullet points, main keywords
- [ ] Set up inventory plan — how many units for the first order?
- [ ] Place inventory order once samples are approved
