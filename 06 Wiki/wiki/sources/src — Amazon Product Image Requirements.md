## What This Source Is

Amazon's official product image requirements for the AU marketplace. Covers technical specifications, main image rules, all-image rules, and what happens if you don't comply. Non-compliant main images result in listing suppression from search — no image, no rank.

---

## Core Sections

1. **Product image requirements and selection** — minimum image count, Amazon's right to select/modify images
2. **Technical image requirements** — file formats, pixel dimensions, resolution, naming conventions
3. **Main product images** — the strict rules for the hero shot (white background, 85% fill, no props, etc.)
4. **Requirements for all product images** — rules applying to every image slot
5. **Troubleshooting** — where to check image upload failures and fix them

---

## Key Facts Extracted

- Minimum: 1 compliant main image to be live
- Recommended: 6+ additional images + 1 video
- Main image: pure white background (RGB 255, 255, 255) — exact values required
- Product must fill **85% of the image frame**
- No text, logos, watermarks, borders, or colour blocks anywhere in main image
- Upload delay: up to 24 hours before appearing on listing
- Non-compliant main image = **listing suppressed from search**
- Amazon may select images from other sellers for your ASIN (Brand Registry limits this)
- First uploaded image defines product identity — never use a placeholder first
