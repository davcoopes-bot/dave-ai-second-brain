## Key Takeaways (from completed modules)

- **Business name = zero-impact decision**: Use initials + "Distribution" or "Wholesale." Customers never see it. Make this a 5-minute call and move on.
- **LLC before Amazon account**: If you're going to form an LLC, do it before setting up Seller Central. Changing structure later triggers extra Amazon re-verification steps.
- **Communication hierarchy**: Open Zoom calls → Facebook group → FAQ. Coaches don't respond to most DMs due to volume.
- **LaunchFast product grading**: Scores products A10 (best) to F1 (worst). B1 and above = worth pursuing. $49/month for LegacyX students (vs $200 general rate). 3-day trial with code QUICKSTART3.
- **FBA-Pro (now at agency-studios.com)**: Laser-etched images for brand approval + GTIN exemption. Brand approval ≠ brand registry. Approval unlocks brand name; Registry (trademark required) gives A+ Content + hijacker protection.
- **Profit margin calculator**: Live Google Sheet — copy it and only edit orange cells. Tracks product cost, packaging, FBA fees, shipping, differentiators. Auto-flags if differentiators push margin below safe threshold.
  Link: https://docs.google.com/spreadsheets/d/19MD78G5xmiV1k_XKHx0GncJKB1nzAgpUwK7kUKMvmLE/edit
- **Brand naming rules**: Avoid common words, trademarks, misspellings. Random nonsense names best. Check: Google → Amazon → USPTO → GS1.
- **Barcode types**: GTIN exemption = no UPC needed. FNSKU (per unit, from Manage Inventory → Print Item Labels). Shipping labels (per box). Pallet labels (rare).
- **Catalogue authorization verification**: Never trust Amazon's email. Test by creating dummy listing — if "Apply" button shows, reapply; if listing creation proceeds, you're approved.
- **Dummy listing process (2025)**: Settings > FBA > FBA Barcode Preference → change to "Amazon barcode" FIRST. Then Add Products → Blank Form → use approved brand name, no UPC, correct category. Skip images so listing stays inactive. Let sit 5–7 days.
- **FNSKU barcode setting fix**: Change FBA Barcode Preference to "Amazon barcode" before creating any listing. Prevents hijackers from easily selling knockoffs.
- **Variations**: Launch 2–3 max. Create child listings first → let sit 5–7 days → then merge under parent. Never launch more than 3 — top 1–3 SKUs generate most revenue. Reviews stack at ~0.4–1% of sales.
- **H10 product research criteria (LegacyX)**: $200K+ niche revenue, $25+ avg price, ≤500 avg reviews (with exceptions), $5K+ avg revenue per seller, top 2-3 sellers <50% of revenue, 30%+ margin before ads.
- **Seller Sprite criteria**: Minimum $5K revenue, $40+ price, ≤500 reviews, FBA, US/China/HK. Use niche-down + rabbit hole strategy.
- **Supplier outreach (LegacyX)**: Contact 15–20 verified suppliers directly (not RFQ first). Choose 4.8+ rated, US-market-focused. State quantity + target price in first message. Pay by credit card via Trade Assurance first; switch to wire only after trust is built.
- **Negotiating**: Alibaba prices are inflated 200–400%. Contact 20–30 suppliers. State how many units you want at your target price — don't ask for quotes. Get separate line items for product, packaging, and accessories. Mention you sell on Amazon. Students regularly hit 45–60% net margins.
- **Profitability targets**: Aim for 35–45% margins — 30% risks ending up below after final costs. FBA fees are based on volumetric (package) weight. Crossing the 18" threshold into large standard/oversize dramatically increases fees. Use H10 calculator with exact supplier package dimensions.
- **LegacyX sourcing partner**: bosssourcing.com — agents find products, negotiate, check quality at 5–7.5% markup. No Alibaba Trade Assurance — use qcadvisor.com for inspections.
- **Shipping terms**: Negotiate EXW (ex-works to supplier door) to see true product cost. Ship DDP with freight forwarder (they handle customs + delivery to Amazon). LegacyX vetted DDP service: Freight Shark.
- **Brand Registry**: Requires trademark application number. Gives A+ content, Vine reviews, anti-hijack tools. Trademark must exactly match brand name (case-sensitive). Photos must show branding on product or printed packaging — NO stickers. Not required early — prioritise post-launch.
