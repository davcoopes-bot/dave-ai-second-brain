## What This Source Is

Amazon's official policy document governing every product detail page on the platform. Covers what sellers can and cannot do when writing listings, adding new pages, editing existing pages, and operating under Brand Registry. This is the rulebook — non-compliance risks listing suppression or account termination.

---

## Core Sections

1. **Policies for Writing Listings** — prohibited content across all fields, title character limits, capitalisation rules
2. **Policies for Adding Detail Pages** — IP rights, GTIN requirements, no duplicate listings, no cross-promotion
3. **Policies for Editing Detail Pages** — what edits are permissible, new version = new ASIN, no re-branding
4. **Brand Registry Guidance** — how contributions are weighted across authorised brand users

---

## Key Facts Extracted

- Title hard cap: 200 characters (recommend ≤80 for mobile)
- Capitalisation: Title Case only — no ALL CAPS
- No HTML, JavaScript, or code in any listing field (line breaks `</br>` allowed in description only)
- Prohibited in ALL fields: prices, URLs, phone numbers, review requests, watermarks, time-sensitive info
- Creating a new listing for a new product version (different colour, size, material, features) = **mandatory new ASIN**
- Re-branding = new ASIN. You cannot change an existing ASIN's brand name.
- GTINs must come from GS1 or with explicit authorisation from the prefix owner
