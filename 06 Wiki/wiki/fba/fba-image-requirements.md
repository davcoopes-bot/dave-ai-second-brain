## Summary

Amazon's image rules are strict and enforced automatically. A non-compliant main image gets your listing suppressed from search before you've made a single sale. These aren't guidelines — they're hard requirements. Get them right before briefing a photographer.

---

## Technical Specs

| Requirement | Spec |
|-------------|------|
| Recommended format | JPEG (.jpg / .jpeg) |
| Also accepted | TIFF, PNG, GIF |
| Minimum size | 500px on longest side |
| Maximum size | 10,000px on longest side |
| Resolution | Must be clear — no pixelation, no jagged edges |
| File naming (optional) | `[product identifier].[variant code].[extension]` e.g. `B000123456.MAIN.jpg` |

> **Zoom tip:** Amazon's zoom function requires 1,000px+ on the longest side. Shoot at minimum 2,000px to give yourself room.

---

## Main Image Rules (The Critical Ones)

The main image is the image shown in search results. Getting this wrong = suppression.

| Rule | Detail |
|------|--------|
| **White background** | Pure white — RGB 255, 255, 255. No off-white, no gradient. |
| **Product fills 85% of frame** | The product itself must occupy 85% of the image area. |
| **No text or graphics** | No text, logos, watermarks, badges, colour blocks, or borders on or around the product. |
| **Full product visible** | Entire product must be within the frame — nothing cut off. |
| **One unit only** | Show only one unit. No front + back in the same image. |
| **No accessories not included** | Only show what's in the box. Extra props = confusion = compliance risk. |
| **No packaging** | Don't show the box or bag unless the packaging is the product (e.g. gift basket). |
| **Lifestyle main image** | NOT allowed for most categories. Only a limited list of product types can use a lifestyle shot as the main image. Default = white background hero shot. |

---

## Rules for All Images (Main + Secondary)

These apply to every image you upload:

- Must accurately represent the product you're selling
- Must match the product's title
- No nudity or sexually suggestive content
- No customer review imagery, star ratings, "Free shipping" or seller-specific claims
- No pricing text (swatch images only)
- **No Amazon logos, trademarks, or Amazon badges** — this includes "Amazon's Choice", "Best seller", "Top seller", "Prime", "Alexa"

---

## What Gets You Suppressed

| Violation | Consequence |
|-----------|-------------|
| No compliant main image | Listing suppressed from search |
| Image fails technical requirements | Cannot upload at all |
| Image violates policy | Removed by Amazon |
| Repeatedly non-compliant | Escalating account risk |

## Image Sequence Strategy

The compliance rules above cover what's allowed. For how to sequence your images to maximise conversion, see [[wiki/fba/fba-listing-optimisation.md]] — image sequence is covered there.

**Short version for splatter screen:**
1. Main — pure white background hero shot, product at 85%, no text
2. Lifestyle — product in use on a hot pan
3. Problem/solution — old splatter mess vs. clean counter with your product
4. Feature callout — silicone handle, mesh density
5. Size/fit — showing coverage of a standard pan
6. Social proof or bundle — if applicable

## Voya-Specific Notes

- **Silicone splatter screen main image:** Hero shot on pure white. Full product visible. No branding text on the image itself (brand name belongs in the listing title, not burned into the main image).
- **Handle differentiation:** The silicone handle is Voya's main differentiator — lead with it in secondary images, not the main. Main stays clean and compliant.
- **Environmental/sustainability claims:** Cannot make unsubstantiated claims in any image (or listing). If Voya makes eco claims, they must be verifiable. See open question in `system/log.md`.
- **"Best seller" badge:** Never add this to your images — even if you earn it on Amazon, you cannot use the badge yourself.

---

## Filing and Uploading

- Amazon may select images from multiple sellers — your image being uploaded doesn't guarantee it displays
- Images can take **up to 24 hours** to appear after upload
- Amazon recommends **at least 6 images + 1 video** per listing
- Fix any compliance issues flagged in Seller Central → Catalogue → Upload Images → Submission Status before re-uploading
